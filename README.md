# 半導體原理及製造概論｜自主學習成果

本自主學習以「半導體原理及製造概論」為主題，透過 EWANT 線上課程、資料查找與筆記整理，從量子理論、原子結構與能帶開始，進一步認識半導體元件、晶片製程、晶圓廠製造管理，以及人工智慧在半導體製造中的應用。

## 學習重點
- 量子理論、原子與晶體結構
- 能帶理論與半導體材料
- 二極體、電晶體與積體電路
- 晶片製程與半導體製造管理
- AI、大數據與資訊科技在半導體產業的應用

## 學習收穫
透過這次自主學習，我逐漸理解半導體並非單一技術，而是結合物理、材料、製造與資訊科技的跨領域工程。學習過程也讓我更加確定自己對電機、資訊與科技相關領域的興趣，並培養主動查找資料、整理複雜概念與持續探索的能力。
